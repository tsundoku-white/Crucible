All dependncies are as such:

- vulkan-icd-loader | loading vk functions
- vulkan-headers | the sdk
- vulkan-tools | tools for vulkan
- vulkan-validation-layers | debugger
- glfw | window creation
- shaderc | to compile .glsl to .spv
- spirv-tools | better compilation
- ninja | build compiler
- cmake | build system
- git | to fetch dependent libs

- drivers this will be done is install script in ./install
